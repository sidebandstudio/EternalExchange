# Changelog

## PE1.1.0 (Fabric) — initial release

First public release of EternalValuePE for Minecraft 1.21.1 (Fabric).

- Complete equivalent-exchange gameplay: EMC engine, Transmutation Table/Tablet, condensers, collectors, relays, matter furnaces, pedestals, alchemical bags/chests
- Dark/Red Matter tool, weapon, and armor lines with charge and modes; Gem armor with abilities and keybinds
- Rings, amulets, stones including Philosopher's Stone with world-transmutation preview
- Klein Stars and the alchemical fuel line (burns in all furnaces)
- Custom EMC via `custom_emc.json` and datapack conversions; TOML config at `config/ProjectE/`
- World/config data compatible with the NeoForge-era format (player knowledge and bags migrate automatically)

Known gaps: no recipe viewer integration yet, no Trinkets support, no fluid pipe/tank interop, server configs not synced to clients. See README roadmap.
